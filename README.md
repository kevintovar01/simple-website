# simple-website

Web project following the Microsoft Learn module [Introducción al desarrollo web mediante Visual Studio Code](https://learn.microsoft.com/es-es/training/modules/get-started-with-web-development/).

## Overview

This repository contains the exercises from the module:
- HTML structure (`index.html`)
- Styling with CSS (`main.css`)
- Interactivity and theme toggling with JavaScript (`app.js`)
